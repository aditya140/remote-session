# QGenie console design review

Extract the complete package and open `index.html`. Keep the local CSS files,
JavaScript files, and `variants` folder beside the page.

Select an admin or owner view. Open Users for a device and agent drill-down.
Open Telemetry & signals for the plots and evidence cards. Switch to My workspace
for owner devices, workload, model coverage, and simulated session controls.

All data is synthetic. Actions change local display state only. No native session
or remote service receives an action. The API documents describe proposed work.

The `previews` folder contains full-size screenshots and a comparison image.
